首次使用按顺序完成前三篇：

1. [01 开始使用](/zh/p/getting-started/)：取得站点，准备工具，预览并添加第一篇文章。
2. [02 设置自己的站点](/zh/p/site-configuration/)：设置网址、站名和语言。
3. [03 首次部署](/zh/p/deploying/)：构建、检查并发布站点。

完成入门后，按标题前缀选择专项：

| 分组 | 使用场景 |
| --- | --- |
| 内容 | 组织栏目与引用，选择列表和图片墙，收录产品 |
| 外观 | 修改页面区域、导航、配色、首页和图标 |
| 运行 | 配置交付、缓存、预取和安全策略 |
| 发布 | 配置站点发现、分享信息和来源链接 |
| 参考 | 查阅项目术语 |

专项之间没有固定阅读顺序。检查工具见[浏览器检查](/zh/p/browser-regression/)；修改主题源码时，转到[开发资料](/zh/articles/docs-dev/)。

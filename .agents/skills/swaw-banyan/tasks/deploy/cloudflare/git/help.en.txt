swban help/en deploy/cloudflare/git  #Prepare Cloudflare Pages Git builds

The platform pulls source and uses swban to build the site and Pagefind search index.

1. Prepare the source: commit swban, .agents/skills/swaw-banyan and the site source. Enable platform.cloudflare.pages.enabled in assets/deploy/settings.toml. Keep replace to ./module when that source is included in the repository; remove replacements pointing outside the repository. Do not commit .tools.

2. Give the platform these build settings:
Root: site directory in the repository (./ for this reference site). Output: public.
Build command: sh swban build --baseURL "$CF_PAGES_URL"
Build image: v3. Environment variable: SKIP_DEPENDENCY_INSTALL=1.
swban reuses compatible tools and downloads missing tools as needed. Configure access to private dependencies separately.

3. Run swban build locally, then check/delivery and check/csp on its output. Pages reads _headers and _redirects from public; no Wrangler configuration is needed.

4. Follow Swaw Clouds for Git authorization, project linkage, platform settings and build triggers:
swcl help/en cloudflare/deploy/pages-git  #Read platform Git build steps
https://github.com/SwawHQ/swaw-clouds/blob/main/skills/swaw-clouds/tasks/cloudflare/deploy/pages-git/help.json
Confirm the deployed commit and output in platform logs, then run swban check/http/security <url> and check changed pages.

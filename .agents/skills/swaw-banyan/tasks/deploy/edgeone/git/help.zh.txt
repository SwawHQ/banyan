swban help/zh deploy/edgeone/git  #准备 EdgeOne Makers Git 托管构建

平台拉取源码，使用 swban 构建页面和 Pagefind 搜索索引。
以下命令在站点根目录的 PowerShell 中执行。只有采用 EdgeOne Git 构建的站点，才需要提交根目录 edgeone.json；交付规则仍在 assets/deploy/ 下维护。

1. 准备源码：在 hugo.toml 中设置 baseURL，并在 assets/deploy/settings.toml 中启用 platform.edgeone.makers.enabled。提交 swban、.agents/skills/swaw-banyan、站点及固定的主题版本；保留随仓库提供的 ./module 替换，移除指向仓库外本机目录的 replace。

2. 向平台提供构建设置：
根目录：站点在仓库中的目录，本参考站点为 ./。输出目录：public。
安装命令：true。构建命令：sh swban build
工具由 swban 复用或按需下载；私有依赖权限按本站需要设置。

3. 提交前先在本地构建、检查并复制交付规则：
swban build                                                               #构建页面和搜索索引
swban check/delivery                                                      #检查交付规则
swban check/csp                                                           #检查 CSP 与脚本
Copy-Item -LiteralPath ./public/edgeone.json -Destination ./edgeone.json  #复制交付配置到站点根目录
提交根目录 edgeone.json。它只含响应头和重定向，不含构建命令或工具版本；这些设置在平台管理。
2026-11-14 实测 Git 构建读取根目录 edgeone.json，不应用构建生成的 public/edgeone.json。交付规则或 CSP 变化后，重新构建并复制；本地与平台的构建结果应保持一致。

4. 仓库授权、项目关联、平台设置和构建触发按 Swaw Clouds 专项操作：
swcl help/zh edgeone/deploy/git  #查看平台 Git 构建步骤
https://github.com/SwawHQ/swaw-clouds/blob/main/skills/swaw-clouds/tasks/edgeone/deploy/git/help.json
发布后核对日志中的提交版本和产物，运行 swban check/http/security <url>，并检查修改的页面。

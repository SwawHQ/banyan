swban help/en deploy/edgeone/git  #Prepare EdgeOne Makers Git builds

The platform pulls source and builds it. It uses native Hugo, not swban.
Run these commands in PowerShell from the site root. Only sites using EdgeOne Git builds need a committed root edgeone.json; maintain delivery rules in delivery.toml.

1. Prepare the source: set baseURL in hugo.toml and enable platform.edgeone.makers.enabled in assets/site/delivery.toml. Commit the site and its pinned theme version; remove local filesystem replace directives.

2. Give the platform these build settings:
Root: site directory in the repository (./ for this reference site). Output: public.
Build command: hugo --minify --gc --cleanDestinationDir
Tools: Hugo Extended meeting the theme minimum; Hugo Modules also need Go and Git. Configure installation steps and private dependency access for the site.

3. Build locally, check output and copy delivery rules before committing:
swban base/hugo --minify --gc --cleanDestinationDir                       #Build production output
swban check/delivery                                                      #Check delivery rules
swban check/csp                                                           #Check CSP and scripts
Copy-Item -LiteralPath ./public/edgeone.json -Destination ./edgeone.json  #Copy delivery config to the site root
Commit root edgeone.json. It contains headers and redirects, not build commands or tool versions; manage those on the platform.
A Git build tested on 2026-11-14 used root edgeone.json and ignored generated public/edgeone.json. Regenerate and copy when delivery rules or CSP change; keep local and hosted output consistent.

4. Follow Swaw Clouds for Git authorization, project linkage, platform settings and build triggers:
swcl help/en edgeone/deploy/git  #Read platform Git build steps
https://github.com/SwawHQ/swaw-clouds/blob/main/skills/swaw-clouds/tasks/edgeone/deploy/git/help.json
Confirm the deployed commit and output in platform logs, then run swban check/http/security <url> and check changed pages.

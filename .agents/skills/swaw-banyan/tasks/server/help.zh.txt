swban server [Hugo 参数...]  #启动开发服并建立搜索索引

hugo server --buildDrafts --disableFastRender --noHTTPCache --port 5678 --bind 127.0.0.1 --renderToMemory=false --cleanDestinationDir=false
预览包含草稿，实时刷新。产物保存在 Hugo 的 publishDir（默认 public/）。附加参数传给 Hugo。

Pagefind 读取临时 pagefind.json。site 为 Hugo 输出目录，output_subdir 为 pagefind。
搜索页的 index.source 决定 glob（索引文件），index.selector 决定 root_selector（页内索引范围）。
启动时建立一次索引。修改内容后，重启命令更新索引。

swban server -p 8080           #改用 8080 端口
swban server -D=false          #排除草稿
swban server -N                #编辑后跳转到对应页面
swban server/lan               #允许局域网访问
swban server/pagefind.off      #跳过搜索索引
swban base/hugo server --help  #查看 Hugo 开发服参数

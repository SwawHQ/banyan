swban dev/build [--destination <directory>] [--baseURL <URL>]  #Build with the local Module and index search

The local Module uses HUGO_MODULE_WORKSPACE=hugo.work and HUGO_IGNOREVENDORPATHS=github.com/SwawHQ/banyan/module.

hugo --minify --noBuildLock --cleanDestinationDir --destination <output directory>
The output directory defaults to public/. Hugo uses the site base URL unless you pass --baseURL.

Pagefind reads a temporary pagefind.json. site is the Hugo output directory and output_subdir is pagefind.
The search page’s index.source sets glob (files to index). Its index.selector sets root_selector (content within each file).

swban dev/build --destination ./preview         #Build into preview
swban dev/build --baseURL https://example.org/  #Set the site URL

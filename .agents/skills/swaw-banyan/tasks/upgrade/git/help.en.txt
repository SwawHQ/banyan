swban help upgrade/git  #Inspect official version changes for a theme upgrade

Inspect changes between official versions, then plan the site upgrade. These examples call native Git through swban base/git.
<official>: absolute checkout path; use swaw/banyan/upgrade/official/ under the system temporary directory.
<old>/<new>: official base/target project tags or commit SHAs.

1. Determine <old> (run from the site root):
swban upgrade/version/current  #Report the current theme's official version or commit (old) and source
If old is null or migration is incomplete, review the configuration, archetypes and affected content against the target reference site.

2. Prepare the official checkout and versions:
swban base/git clone https://github.com/SwawHQ/banyan.git "<official>"      #Clone the official repository once
swban base/git -C "<official>" fetch origin --tags                          #Update an existing checkout
swban base/git -C "<official>" tag -l "v*" --sort=-version:refname          #List official versions
swban base/git -C "<official>" rev-parse "<old>^{commit}" "<new>^{commit}"  #Resolve the confirmed baseline and target to commit SHAs

3. Compare site configuration, archetypes and local overrides
swban base/git -C "<official>" diff --name-status -M <old> <new> -- assets/ module/archetypes/  #List added, deleted, modified and detected renamed or moved files
swban base/git -C "<official>" diff <old> <new> -- hugo.toml assets/ i18n/                      #Review settings, assets and interface dictionaries
swban base/git -C "<official>" diff <old> <new> -- module/archetypes/                           #Review archetype changes
Use the archetype changes to check content in each language and parent cascades. Map module/archetypes/assets/ to the site’s assets/ directory and preserve local setting values.

For site overrides, compare the corresponding upstream paths. For extensive customizations, optionally list all changes:
swban base/git -C "<official>" diff --name-status -M <old> <new> -- module/  #Find affected overrides by old and new path

If the old version lacks a prototype or a file was split, compare the source files and the code that reads them in both versions to trace the affected fields. Review maps or resource bundles for affected features.

4. Upgrade the matching Skill and theme:
Update the complete .agents/skills/swaw-banyan/ from target project tag vX.Y.Z for use with theme vX.Y.Z; changing metadata.version alone does not update the Skill.
swban doctor  #Check theme and Skill pairing after the upgrade
Then build the site. Check the minimum Hugo version, local template overrides and affected features.

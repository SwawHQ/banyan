swban check/browser/nav/tabs [dir] [--headed] [--trace] [--out <dir>] [--timeout <ms>] --page <path> [--selector <css>]  #原生新标签页与 opener 隔离；Chromium

  dir               已完成的站点构建目录；默认：public
  --headed          显示浏览器窗口
  --trace           保存 trace.zip；默认输出到系统临时目录
  --out <dir>       在新子目录保存 JSON 和截图
  --timeout <ms>    浏览器启动和单次操作的超时，单位为毫秒；默认：15000
  --page <path>     已构建且含新标签页链接的页面
  --selector <css>  待激活链接的 CSS 选择器；默认：.slot-main .prose a[target="_blank"]
